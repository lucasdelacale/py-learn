# Python 3 - Aprendizado

Repositório de estudos do curso [Python 3 do Básico ao Avançado](https://www.udemy.com/course/python-3-do-zero-ao-avancado/) da Udemy.

## Sobre o Curso

Curso completo de Python 3 do básico ao avançado com projetos reais. Mais de 140 horas de conteúdo cobrindo:

- Lógica de programação básica
- Programação procedural e funcional
- Programação orientada a objetos (POO)
- Módulos Python (os, datetime, json, csv, selenium, pillow)
- Interface gráfica com PySide6 (Qt 6)
- Bases de dados (SQLite e MySQL)
- Django (sites e APIs)
- Design Patterns (GoF)
- Expressões Regulares (RegEx)
- Testes automatizados (Pytest, Unittest)
